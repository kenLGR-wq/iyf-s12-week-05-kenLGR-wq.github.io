## Project Description
An interactive webpage created to practise JavaScript fundamentals, including variables, functions, events and DOM manipulation.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## Features
- Personalised greeting form
- Interactive click counter
- Light and dark mode
- Responsive webpage
- JavaScript learning checklist

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Open index.html in your browser.

## Lessons Learned
- Declaring variables using let and const.
- Creating and using functions.
- Using event listeners.
- Manipulating HTML elements using JavaScript.
- Connecting JavaScript to HTML and CSS.

## Challenges Faced
Connecting JavaScript functions to HTML elements and handling user input. I solved these challenges using querySelector(), addEventListener() and basic input validation.
